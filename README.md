# 寻迹 · 收纳保质期记录（单机本地版）

黑白极简的单机收纳 App。所有数据保存在浏览器 `localStorage`，不需要账号、不需要后端、不需要联网，也没有好友、聊天、社交、协作或分享功能。

## 界面

- 底部 5 个入口：首页、分类、绿色加号、联动、我的；第二个图标换成九宫格，绿色加号在所有页面常驻
- 全 App 所有页面只要内容超出屏幕都可直接滚动，不再锁死；首页标题栏随内容一起滚走，只有底部五个图标固定
- 适配 iPhone 安全区与动态视口高度，刘海屏底部导航不会被裁掉
- 页面不绘制假状态栏，时间、电量等使用手机系统状态栏
- 左侧抽屉已删除，首页左上角三条横线按钮也一并移除；首页顶部标题显示“寻迹”
- 首页搜索框灰色略微加深、占位文字只显示“搜索”，可直接输入并即时显示结果，不用跳到第二页；排序行右侧可一键把物品列表折叠为空白，再点展开，多选圆圈只在多选模式出现
- 物品标签横向可滑动，右侧显示主题色库存小胶囊；未拍照的物品按名称显示线稿小图
- 有临期 / 过期物品时，首页物品列表上方出现到期预警；点进去是独立详情页，可返回或逐条“删除提醒”，只删提醒不删物品，不删除则返回后提醒仍在
- 实体表情图标（🧺✅⏰🚫📂🏬🗑️🗂️）以四列宫格放在第二页“分类”，图标与文字中心对齐、左右边距等距；底部只显示居中的“按状态快速查看物品”。分类标题栏使用固定顶部 header，与“设备联动”同一位置、字体大小和图标颜色，右上角是通知铃铛。全部 / 状态良好 / 临近过期 / 已过期等入口使用真实状态筛选，中文界面显示中文，“全部”显示所有未删除物品；分类管理和分类详情内容超出屏幕都可上下滑动
- 首页与分类页使用淡绿渐变和气泡装饰，不再冷清
- 进入临近过期 / 已过期等筛选页后，标题栏左侧返回键回到全部分类；从分类页或分类管理进入的详情则返回对应来源页
- 老年模式整体约 1.12 倍，底部图标不再夸张放大；标准 / 大字 / 超大分别为 1 / 1.08 / 1.16 倍，文字按比例变化
- 搜索历史保存在本机，第二页已改为分类导航，不再显示搜索内容
- 底部绿色加号直接进入新增物品表单，编辑页为独立页面不显示底部导航
- 联动页未验证设备时不显示设备号和地图；用户自行填写设备号、密码，验证正确后才显示物品实时位置、距离与设备卡片
- 联动页合并为一张实时定位地图卡片，刷新 / 获取位置 / 全屏地图 / 选择地图都放在地图内；卡片、按钮行和地图高度已压缩，下方绑定设备更容易直接看到
- 打开联动页会主动请求系统定位权限，地图顶部显示“已获取我的位置 / 定位权限未允许 / 正在请求定位权限”等状态；拒绝后仍可点“获取位置”重试
- 内嵌地图改为高德官方 JS API 矢量地图（使用项目内配置的 Key 和安全密钥），清晰度、配色和建筑渲染与高德官方页面一致；不加载邀请好友、打车、导航弹窗等第三方页面内容
- 地图内只保留物品照片/动物图标和名称的小气泡，固定在设备真实坐标上，拖动和缩放地图时始终跟随
- 灰色信息区显示纬度、经度、定位时间、电量和“我到物品距离：约 X 米 · 静止 / 移动中”，状态根据物品定位实时变化
- 地图右上角可切换“地图 / 卫星”；地图支持自由拖动、缩放，小窗口默认放大一级以显示更具体的位置，全屏地图覆盖原页面并带返回按钮
- 「我的 / 头像框」页内容整体上移，顶部间距与设备联动页一致
- 底部“展开”已删除，改为“选择地图”弹层，可选高德 / 百度 / 腾讯 / 谷歌直接打开；内嵌地图使用高德 JS API Key，需在控制台把 `ananpaofu.github.io` 加入白名单；高德未加载时会自动切换备用地图
- 定位参数由内置服务实时解析，界面不显示第三方名称，也不需要用户填写任何定位链接
- 设备联动绑定流程：选择已有物品或新建物品、拍照或从相册选图并选择“直接使用 / 自定义裁剪”、自行填写设备号和密码，验证正确后才显示物品照片、实时位置和距离
- 分类页右上角铃铛 / 「我的 → 通知中心」打开通知页，可按全部、过期、临近过期、库存、系统、其他筛选并按日期分组
- 「我的」页可上下滚动，个人信息 / 界面设置 / 功能设置标题可点击收起；可修改昵称、联系方式、签名、通知时间，并进入成就 / 装扮、修改密码、图文使用指南
- 新增物品页字体和间距加大，但仍保持一屏显示所有可填写内容
- 成就页等级横向一排，卡面、头像框、动物头像框随等级解锁
- 字体大小、字体粗细、界面颜色、语言（跟随系统 / 简中 / 繁中 / 英文）均可调，切换后全站文字同步；老年模式独立开启，按比例温和放大
- 「消息通知」开关已移除；通知中心与提示音使用不同图标，通知中心 / 使用指南返回“我的”
- 通知时间使用主题色自定义选择器，分钟可精确到任意 1 分钟；日历“清除”只取消选中圆圈，“取消”返回表单
- 成就卡面改为居中头像 + 渐变卡片；新增分类自动识别拼音首字母（水果 → S、哭 → K）放入灰框，按 A-Z 排序；分类管理添加框在最上方，点分类进入独立分组页，不再跳首页
- 成功提示为绿色胶囊弹窗（带 ✓），停留约 3.6 秒，方便看完文字
- 隐藏注册页保留，访问 `https://ananpaofu.github.io/new-shouna-app/#register` 可打开

## 功能

- 本地新增 / 编辑 / 删除 / 恢复物品
- 记录名称、多张图片、生产日期 / 保质期、分类、数量与单位、存放位置、备注
- 首页状态筛选：全部、状态良好、临近过期、已过期、已开封、库存总览、回收站
- 首页搜索框本地搜索，保留最近 10 条搜索历史；语音搜索调用手机麦克风（Web Speech API），实时转文字并区分权限 / 网络 / 无声音提示
- 首次进入且完全没有本地存档时显示 2 个示例物品；一旦有已保存物品，示例不会再出现，也不会覆盖之前录入的数据
- PWA 检测到新版本会自动激活并刷新；资源 URL 带版本号避免浏览器缓存。「我的 → 版本与更新」里可点“刷新检查更新”强制拉新版（清除站点数据会同时删除本地物品）
- 首页排序：名称 A-Z、剩余库存、最近生产、最近过期、最近临期、最近添加、最近更新
- 首页多选：全选、按项选择、批量删除
- 新增物品选一张照片后可选“直接使用”或“自定义裁剪”（拖动、缩放后导出方形图）；多张选择时直接添加，不限制图片尺寸；“我的”页头像从拍照或相册选取后也同样进入“直接使用 / 自定义裁剪”选择
- 显示偏好可静态切换，设置保存在本机

## 云端设备服务（Cloudflare Worker + KV）

不需要商家接口；云端只保存你自己设定的设备号、密码哈希和物品信息，用于多手机绑定和读取内置定位服务。界面不会显示第三方名称。

1. Cloudflare 控制台 → **Workers & Pages → KV** → 创建命名空间，例如 `device_kv`
2. **Workers & Pages → Create Worker** → 粘贴 `device-worker.js` 全部内容 → Deploy
3. 进入这个 Worker → **Settings → Variables → KV Namespace Bindings** → 添加：变量名 `DEVICE_KV`，值选刚建的 `device_kv` → 再 Deploy
4. 浏览器打开 `https://你的worker.workers.dev/api/device`，看到 `{"ok":false,"error":"缺少 code 参数"}` 说明部署成功
5. App 里「绑定设备」→ 选物品、照片，填设备编号和密码（默认 `672305585540` / `123456`），并在“云端 API 地址”填 Worker 根地址（如 `https://xxx.workers.dev`）→ 完成后会显示分享码
6. 设备编号和密码是机主自己设定的 App 绑定凭证，不是商家账号
7. 朋友在设备卡片点「连接设备」→ 填同一个云端 API 地址和机主给的分享码，也可以填设备号 + 密码
8. 连接后「刷新位置」走云端接口，云端每次实时解析内置定位源，并把最新位置缓存到 KV；每部手机都会请求自身定位，地图和距离按各自当前位置计算
9. 内置定位源到期后，由开发者更新内置参数并重新上传，用户无需操作

## 本地运行

直接用浏览器打开 `index.html` 即可。若需要 PWA / Service Worker 的完整行为，可用本地服务器：

```bash
# Python
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 上传 GitHub Pages

在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\Xieta\Desktop\Tracking-main\upload-app.ps1"
```

提示填写时：

1. `GitHub username (owner)`：填 `ananpaofu`，或直接回车（脚本已默认）
2. `Repository name`：填 `new-shouna-app`，或直接回车（脚本已默认）
3. `Branch`：直接回车（默认 `main`）
4. GitHub classic token：粘贴带 `repo` 权限的 classic token

上传后打开 `https://ananpaofu.github.io/new-shouna-app/`，等待 1–2 分钟，强制刷新 2–3 次以更新 Service Worker 缓存。

仓库 **Settings → Pages** 中 Source 选择 **Deploy from a branch**，分支 `main`，目录 `/ (root)`。
