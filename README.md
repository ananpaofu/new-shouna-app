# 收纳小管家 · 手机版

一个纯前端的物品收纳记录 App，让每件物品都有迹可循。数据保存在浏览器本地，无需联网即可使用。

## 功能特性

- **新手教程**：首次进入自动弹出 7 步图文引导，按真实页面逐步列出操作；新用户自带 3 件示例物品
- **物品管理**：拍照识物（本地 AI 模拟）、分类、数量、保质期、存放位置；物品照片 / 存放地点照片 / 保质期照片均支持多张且选填，首页卡片优先展示存放地点照片，无照片时自动配默认示意图
- **智能排序**：到期优先 / A-Z 字母 / 最近收纳；A-Z 索引竖排贴右，物品收起只显示名称，展开看详情
- **收纳地图**：从功能中心进入，按位置（冰箱、柜子等）归类，支持自定义位置自动同步
- **搜索**：位于「我的物品」板块内，支持历史记录、展开、一键清空
- **到期提醒**：临期与过期物品自动排前，从功能中心进入后返回仍回到功能中心
- **设备联动**：顶部醒目高德地图方框（可下拉展开）、蓝牙模拟搜索连接、定位标签查找、离位提醒
- **高德地图联动**：一键唤起手机上的高德地图 App（无需 Key、无需配置），位置自动带入；未安装时回退到网页版
- **成就装扮**：从功能中心进入，收纳升级解锁头像框 / 名片 / 徽章，可在成就等级中佩戴，好友资料中可见
- **好友与群聊**：编号 ID 加好友（内置好友目录可搜索 / 一键添加）、点头像进好友主页、文字、表情、表情包导入、聊天背景更换、删除好友
- **社区动态**：发布图文动态、点赞、进入评论区发表评论（评论入口不再跳群聊）
- **个性化设置**：微信风格设置页，可改头像昵称；字号四档、字体粗细四档与主题色即时生效；老年模式提供超大字体与高对比配色并简化功能；分组可折叠；退出登录有二次确认
- **安装到桌面**：功能中心「安装到桌面」按安卓 / 苹果自动给出对应图文步骤，一键安装（安卓 PWA）

## 本地运行

直接用浏览器打开 `index.html` 即可。

若要完整测试拍照、定位等需要安全上下文的功能，可用本地服务器方式打开：

```bash
# Python
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将本目录下的所有文件上传到 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`
4. 保存后等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`

## 安装到手机桌面（PWA）

部署到 GitHub Pages（HTTPS）后：

- **安卓 Chrome**：打开网址 → 右上角菜单 → 「安装应用 / 添加到主屏幕」，确认后即可像普通 App 一样全屏打开。
- **苹果 Safari**：打开网址 → 底部分享按钮 → 「添加到主屏幕」。

> 必须把所有文件（含 `manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png`）一起上传，且通过 HTTPS 访问（GitHub Pages 符合），浏览器才会显示安装选项。PNG 图标是 Chrome 判断是否可安装的关键，缺少会导致「安装应用」无反应。

> 安卓如点了「安装应用」没反应，可用功能中心的「安装到桌面」按钮直接触发安装；若菜单里没有该项，按弹出的图文步骤手动添加即可。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 入口页面（手机外框 + 状态栏 + PWA 安装事件捕获） |
| `manifest.webmanifest` | PWA 应用清单（安装到桌面用，含 PNG 图标） |
| `sw.js` | Service Worker（离线缓存 / PWA 安装用） |
| `icon-192.png` | PWA 图标 192×192（安装必需） |
| `icon-512.png` | PWA 图标 512×512（安装必需） |
| `mobile.css` | 全部样式 |
| `mobile.js` | 全部逻辑（约 3000+ 行，纯原生 JS，无依赖） |

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无任何第三方依赖
- 数据通过 `localStorage` 持久化（key: `organizer_db_v1`）
- AI 识物、蓝牙连接、跨用户好友均为本地模拟，无后端服务
- 高德地图联动使用高德官方 URI（`https://uri.amap.com/marker?...&callnative=1`），iOS Safari / 安卓均可唤起本机高德 App，无需申请 Key；仅 App 内嵌网页地图时才需要 Web 端 JS API Key，该项为选填并保存在浏览器本地
- 支持响应式：桌面显示手机外框，手机端全屏显示
